🔍 搜索栏在手机上变空白怎么办？Search bar shows blank on mobile?

▼

此问题已在最新版本修复（2026年5月）。原因是手机键盘弹出时压缩了页面高度导致内容消失。现在使用动态视口高度（dvh）技术，键盘弹出后页面内容保持正常显示。如仍有问题，请强制刷新页面（Ctrl+Shift+R / Cmd+Shift+R）。

This issue was fixed in the latest version (May 2026). The cause was the mobile keyboard shrinking the viewport height, hiding the content. The fix uses dynamic viewport height (dvh) so content remains visible when the keyboard opens. If the issue persists, force-refresh the page (Ctrl+Shift+R / Cmd+Shift+R).

💾 数据是实时同步的吗？Is data synced in real time?

▼

是的。所有客户、案件、备注等数据通过 Supabase 云数据库实时同步。任何团队成员的修改，其他人刷新页面后即可看到。建议定期刷新页面以获取最新数据。

Yes. All client, case and note data is synced via Supabase cloud database in real time. Changes by any team member are visible to others after a page refresh. We recommend refreshing periodically for the latest data.

🤖 AI 功能如何使用？How to use AI features?

▼

系统内置多个 AI 功能：

The system has multiple built-in AI features:

  • 微信分析：在客户详情 → 微信标签，粘贴聊天记录，AI 提取摘要和待办
  • WeChat Analysis: Client detail → WeChat tab, paste chat export, AI extracts summary and action items
  • 文档解析：在客户详情 → 导入文档，上传 Word/PDF，AI 自动填充档案字段
  • Document Parsing: Client detail → Import Doc, upload Word/PDF, AI auto-fills profile fields
  • 案件 AI：在案件详情页点击 AI 助手，可生成摘要、分析文件缺口、起草邮件
  • Case AI: In case detail, click the AI assistant to generate summaries, analyse document gaps, draft emails
  • 收件箱 AI：收到消息后 AI 自动起草回复，人工审核后发送
  • Inbox AI: AI auto-drafts replies to incoming messages; send after human review

📄 如何生成服务合同？How to generate a service contract?

▼

在客户详情页（或编辑客户弹窗底部），点击 "📄 生成合同" 按钮。系统会根据客户档案和关联案件自动生成 Word 格式合同，包含 Ozsky 预设银行账户信息。

In the client detail page (or at the bottom of the Edit Client modal), click "📄 Generate Contract". The system auto-generates a Word contract based on the client profile and linked cases, including Ozsky's pre-set bank account details.

🔄 如何关联家庭成员（副申请人）？How to link family members (secondary applicants)?

▼

在客户详情页的 "档案" 标签中，找到 "关联客户" 部分。可将配偶、子女、父母等关联到主申请人，支持的关系类型：主申请人、副申请人、配偶、子女、父母、监护人、担保雇主、附属申请人。

In the client detail Profile tab, find the Linked Clients section. Link spouses, children, parents etc. to the primary applicant. Supported relation types: Primary, Secondary, Spouse, Child, Parent, Guardian, Employer, Dependent.
